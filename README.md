## 🚀 Projetos em Destaque

### 🚗 Vag — Plataforma de Telemetria Automotiva com IA
> Projeto pessoal em desenvolvimento ativo. Telemetria em tempo real para veículos Volkswagen da plataforma **MQB** com análise generativa via IA — diagnósticos inteligentes, dashboards e alertas preditivos.

**Stack:** Java 25 · Spring Boot 4.1 · Spring WebFlux · LangChain4j · GPT-4o · Apache Kafka · InfluxDB 2.7 · Redis 7 · Next.js 15 · React 19 · Kubernetes

---

### 🎓 Plataforma EAD — Arquitetura de Microserviços
> **8 microserviços independentes** com arquitetura hexagonal, circuit breaker com Resilience4j, autenticação JWT, configuração centralizada e observabilidade com Elastic Stack.

**Stack:** Java · Spring Boot · Resilience4j · Spring Cloud Config · JWT · Docker · Elastic Stack

---

### 🍽️ [Controle na Mão](https://encurtador.com.br/guDXZ)
> Sistema de comanda eletrônica para restaurantes com integração iFood — desenvolvido na Nextage para otimizar atendimento e gestão de pedidos em tempo real.

**Stack:** Java 8 · Android Native · Ionic · iFood API
